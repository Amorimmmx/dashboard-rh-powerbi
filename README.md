#  Dashboard de RH — Power BI

Dashboard desenvolvido para análise de indicadores de **Recursos Humanos**, com o objetivo de transformar dados de funcionários em informações visuais para acompanhamento e análise do quadro de colaboradores.

##  Sobre os dados

A base utilizada contém informações de **234 funcionários**, incluindo dados como:

- **ID do funcionário**
- **Nome**
- **Gênero**
- **Cidade**
- **Data de contratação**
- **Data de demissão**
- **Salário**
- **Cargo**
- **Área**
- **Horas extras**
- **Avaliação do funcionário**

##  O que o dashboard apresenta

### Indicadores

- **Contratações**
- **Funcionários ativos**
- **Funcionários desligados**
- **Turnover**
- **Média de avaliação dos funcionários**

### Gráficos e análises

- **Funcionários ativos por cidade:** distribuição dos funcionários ativos entre as diferentes cidades presentes na base.
- **Funcionários ativos por gênero:** visualização da distribuição dos funcionários ativos por gênero.
- **Funcionários por área e cargo:** análise da distribuição dos funcionários entre as áreas e seus respectivos cargos.
- **Contratações ao longo do tempo:** acompanhamento da quantidade de contratações utilizando a data de contratação.

##  Principais aprendizados

Durante o desenvolvimento do projeto, foram praticados conceitos como:

- Criação e utilização de **medidas DAX**
- Cálculo de **funcionários ativos**
- Cálculo de **funcionários desligados**
- Cálculo de **Turnover**
- Criação de **indicadores (Cards/KPIs)**
- Criação e configuração de gráficos
- Utilização de **gráfico de linhas**
- Utilização de **gráfico de rosca**
- Análise de dados por **gênero**
- Análise de dados por **cidade**
- Análise de dados por **área e cargo**
- Criação de filtros e interação entre os elementos do dashboard
- Organização e apresentação visual de indicadores de RH

##  Ferramentas utilizadas

- **Power BI Desktop**
- **DAX**
- **Microsoft Excel**
